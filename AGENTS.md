# Puzzle World — geração de artes

Para pedidos de gerar, continuar, regenerar, revisar ou aplicar artes das cartas,
leia `tools/card-image-generator/AGENT_WORKFLOW.md` e use a ferramenta existente.
O usuário escolheu geração integrada pelo Codex/ChatGPT, sem API paga ou chave.
Não recrie o catálogo, as molduras ou a interface do jogo.

Por preferência expressa do proprietário, execute no máximo cinco testes focados por tarefa. O proprietário fará a validação complementar no celular real. Evite rodar a suíte completa em alterações pontuais.
